I'm a software engineer who likes the parts of the stack other engineers find scary — concurrency, distributed coordination, low-latency network code, and the boring plumbing that keeps production-grade systems running.

On the side I ship a portfolio of 11 open-source repos covering DevSecOps (Kubernetes + Vault + Sigstore + Falco), distributed Java (Kafka, SAGA orchestration, Spring Cloud Gateway, a Redis clone in Netty), and IaC security tooling. Every claim in those READMEs has a verify script that proves it.
